# MILCHECK

병역판정검사를 앞둔 사용자가 공식 기준과 검사 절차를 쉽게 탐색할 수 있도록 만든 정적 웹서비스입니다.

## 운영 원칙

- 병무청 공식 서비스가 아닌 독립 정보 서비스입니다.
- 입력한 건강정보는 서버, URL, localStorage, sessionStorage에 저장하지 않습니다.
- 신장·체중 항목만 현행 법령의 표를 기준으로 계산합니다.
- 질환·정신건강은 자가진단이나 최종 등급 산출을 하지 않습니다.
- 실제 신체등급과 병역처분은 공식 병역판정검사에서 결정됩니다.

## 로컬 실행

1. `npm run build`
2. `npm run preview`
3. `http://127.0.0.1:4173` 접속

외부 패키지가 필요하지 않은 정적 HTML/CSS/JavaScript 구조입니다.

공개 주소: `https://leejinho970715-star.github.io/milcheck/`

## 공식 자료 및 데이터 갱신

- 병무청 병역판정검사 과정 및 지참물
- 국가법령정보센터 「병역판정 신체검사 등 검사규칙」
- 병역법 제12조 및 제14조

법령 개정 여부를 확인한 뒤 `src/app.js`의 `calcGrade`, BMI 기준표, 등급 안내를 함께 수정하고 경계값 테스트를 다시 수행합니다. 화면 정보 확인일은 2026-11-26입니다.

## 배포 전 점검

- `npm run build` 및 `node --check src/app.js`
- BMI 경계값: 140.0 / 140.1 / 146.0 / 159.0 / 204.0cm, 15.0 / 18.5 / 20.0 / 25.0 / 30.0 / 40.0
- 모바일 메뉴, 단계 이동, 건너뛰기, 초기화, 검색 필터, 인쇄/PDF
- 모든 페이지 title, description, canonical, OG, JSON-LD
- `/sitemap.xml`, `/robots.txt`, Favicon, 404
- 입력값이 URL·브라우저 저장소·콘솔에 남지 않는지 확인

## 검색엔진 등록

배포 도메인의 소유권을 확인한 뒤 Google Search Console과 네이버 서치어드바이저에 `/sitemap.xml`을 제출합니다. 제출은 색인 완료를 보장하지 않으며 검색엔진의 처리 상태를 별도로 확인해야 합니다.
